# Pro reports

* **Show Topology Check**: Bindings to missing queues or exchanges, missing dead-letter exchanges, unbound queues, unused exchanges and policy problems.
* **Show Security Review**: The guest user, administrator accounts, users without passwords, MD5 hashes, full permissions and unused virtual hosts.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
