# Getting started

1. Install **Queue Definitions Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a RabbitMQ definitions export (JSON from rabbitmqctl export_definitions or the management UI), or run **Queue Definitions Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `Queue Definitions Atlas` and pick a report. The button in the editor title bar of JSON files whose name contains definitions runs **Show Definitions Summary**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **Queue Definitions Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
